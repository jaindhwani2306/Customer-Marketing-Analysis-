# Marketing Analytics Dashboard

## Overview
This project is an interactive Power BI dashboard designed to analyze customer behavior, marketing performance, and enrollment trends. The dashboard provides actionable insights into customer spending patterns, web purchase activity, and demographic segmentation to support data-driven marketing decisions.

---

## Dashboard Features

### Customer Purchase Analysis
- Analyzes the relationship between:
  - Number of Web Purchases
  - Number of Web Visits per Month
- Helps identify customer engagement and purchasing behavior trends.

### Customer Enrollment Tracking
- Monthly enrolled customer analysis
- Cumulative enrollment trend visualization
- Quarterly performance monitoring

### Customer Segmentation
Interactive filters for:
- Marital Status
- Education Level
- Age Group

### Spending Behavior Insights
- Average spending comparison across:
  - Education categories
  - Marital status groups
- Identifies high-value customer segments.

---

## Key Insights
- Customers with higher education levels tend to show increased average spending.
- Certain marital status groups demonstrate stronger purchasing behavior.
- Enrollment trends reveal seasonal growth patterns.
- Web visit frequency influences purchase activity.
